# Neritic (formerly CoastWatch)

**Neritic — Coastal intelligence, grounded in evidence.**

The product was called CoastWatch until October 2026. NOAA has run a program of that name for decades: **NOAA CoastWatch** (coastwatch.noaa.gov, and the West Coast node coastwatch.pfeg.noaa.gov), and this project uses its satellite data. The rename removes any suggestion that the project is NOAA's. "Neritic" is the oceanographic term for the shallow waters over the continental shelf, where the blooms, fisheries and harvests this project describes are. The name also leaves room for the broader scope: fishing intelligence, environmental forecasting, research, and later an evidence-grounded assistant.

> Neritic is an independent research project and is not affiliated with or endorsed by NOAA, CDFW, or CDPH.

**Name history.** The first draft of this rebrand (PR #62, 2026-10-15) used the working name "Neritic Signal". It was shown only on a private preview and never released. The owner chose the single word **Neritic** the same day; the PR was updated in place.

### 1c. Assessment
- "Neritic" alone is a dictionary term from oceanography. For ocean information services it may be judged **descriptive**, which makes it weaker to protect, while others remain free to use it in their own names.
- **Every conflict found is a different good, a different country, or an unregistered business.** None is a live U.S. registration. The two to watch are **Neritic Diving** (overlapping audience) and **The Neritic** (overlapping category).
- **Ways to reduce the risk without changing the name:**
  - pair it with the tagline and the distinctive mark;
  - stay away from wave artwork next to the word, and from selling diving or fishing gear;
  - never use "The Neritic";
  - if a compound is ever needed for registration, use a distinctive one such as "Neritic Coastal Intelligence".

## 2. What changed
- **Name and identity.** A new mark (`components/brand/BrandMark.tsx`) keeps the navy tile, cyan and amber, and draws the neritic zone in cross-section: the sea surface, the shelf and its break into deep water, the shallow band between them lit, and one amber point in it, an observation. No wave artwork (see §1c). The wordmark sets "Neritic" as one word in one weight.
- **Every user-facing surface:**
  - the masthead, footer and Welcome;
  - About and Data & sources;
  - My Coast, the Science tab and the HAB briefing;
  - the official notice texts;
  - Bloom, Fisheries and the map;
  - loading and outage states;
  - kept (printable) briefings, including the downloaded file name `neritic-…html`;
  - API error text.
- **Browser and metadata:**
  - page titles (template `%s — Neritic`);
  - description, Open Graph and Twitter cards, with a generated 1200×630 image (`app/opengraph-image.tsx`);
  - favicon, SVG icon, Apple touch icon;
  - web app manifest (`app/manifest.ts`) with 192, 512 and maskable icons.
  - Regenerate the icons with `node scripts/build_brand_assets.mjs`.
- **Independence statement:** About and Data & sources state it in full; the footer states it in one small line.
- **Published text written by the pipeline:**
  - the registry's source name;
  - the port-chlorophyll method;
  - tile notes;
  - the multi-sensor display's source and institution;
  - the fisheries tier note;
  - the health message;
  - the official-review issue body.
  - These values reach production on the first scheduled run after merge. **No schema or field changes.**
- **READMEs:** they introduce Neritic and say "formerly CoastWatch" where that helps.

## 3. What did not change: NOAA CoastWatch
These keep their original words:
- every reference to **NOAA CoastWatch** as a data provider;
- its hosts (`coastwatch.noaa.gov`, `coastwatch.pfeg.noaa.gov`) and dataset ids;
- product names ("CoastWatch West Coast", "NOAA CoastWatch / NESDIS STAR", "CoastWatch ERDDAP").

The replacement was done line by line with exclusions for these, not as a global substitution, and `tests/e2e/brand.spec.ts` checks that /sources still credits NOAA CoastWatch.

Also unchanged:
- the paper's title, DOI and findings;
- historical documents under `docs/coastwatch/` and `research/`;
- release records and tags;
- logs and checkpoints.

## 6. Domain and brand strategy (recommendation, nothing bought)
1. **Clear the name first** (§1): counsel's search covering U.S. common law and, if relevant, Australia, the UK and India. Decide whether to approach Neritic Diving.
2. **Domain, in order of preference:**
   - **neritic.com**, if an aftermarket price is acceptable: the cleanest single-word identity. Ask NameFind for a quote; buy nothing until the name is cleared.
   - Otherwise **neritic.app** or **neritic.ai** (both unregistered on 2026-10-15). `.app` and `.dev` are HTTPS-only by design, which suits the site. `.ai` signals the future assistant but costs more and renews in two-year terms.
   - Defensive: **neritic.org** (unregistered), and `getneritic.com` as a .com fallback.
   - Avoid `theneritic.*`, already used by the Indian software company.
3. **Handles:** GitHub `neritic` is taken (dormant since 2011). Use `neriticapp` if an organisation is needed, and check social handles when signing in.
4. **Move without breaking anything:**
   - Add the domain to the `coastwatch-demo` Vercel project as the primary domain. Keep `coastwatch-demo.vercel.app` serving the same deployment, or 308-redirecting with path and query preserved, so the BASES link and every shared link keep working.
   - Set `CW_SITE_URL` to the new origin for canonical and Open Graph URLs.
   - Rename the Vercel projects and the repository only after that, if at all. GitHub redirects renamed repositories, but the data URL `yashnil.github.io/habs-forecast/v1` is read by every deployed version, so keep it, or publish to both during a transition.
5. **Naming within the brand:** the product is "Neritic". Name future parts by plain description, for example "Neritic briefings" or "Neritic research"; an assistant could be "Ask Neritic". Never write "The Neritic".
