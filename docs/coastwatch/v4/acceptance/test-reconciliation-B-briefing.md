### Behaviour regressions found while auditing (code, not just tests)
1. **A fully clouded satellite day is not reported.** v2 said "No clear observation on Wed, Oct 7" (v2 LayerDock). v4 has no per-day coverage or no-observation text (grep `src/v4`: none). The timebar offers `time-2026-10-07` (fixture: observed_fraction 0, no tiles). `stamp-satellite` then reads "overpass Wed, Oct 7" over an empty map.
2. **The region-specific HF-radar gap stamp is never produced.** `LayerPanel.tsx:257` calls `stampLines` without `region`, so `stamp-currents-gap` ("No radar observations in North Coast this hour: no data, not calm water", `lib/stamp.ts:113`) cannot appear. Only the generic legend sentence remains.
3. **A failed update can still read as ready, and satellite data is never classed stale.** In v4 Explore, satellite freshness is never classified as current/stale/historical (no `classifyTime` in `src/v4/explore`). `forecastFreshness` → `classifySource` (`lib/freshness.ts:48`) ignores `outcome: "failed"`. With the FAILED fixture, the status centre can show the model as Ready. The only warning is `provenance-status` ("The last update did not complete…", `LayerPanel.tsx:275`), which is untested. It is also per source, not per product: VIIRS and OLCI get the same line.
4. **The closure line is no longer a link.** The CDFW closure line in "Before you go" renders as text (`Briefing.tsx:395-397`), not a `tel:` link as in v2. The checklist also renders shown and more together (`Briefing.tsx:383`), so the "at most five" cap is no longer visible.
5. **Outage technical codes are now visible.** The NWS outage step shows the technical reason, e.g. "(HTTP 503)", in visible text (`lib/nextSteps.ts:230`). v2 kept it in a `title` attribute only.
6. **Removed with no successor:** home-port set/clear (`Briefing.tsx:45` only reads `cw-home-port`), choosing waters by clicking the map (locator `onPoint` is a no-op, `Briefing.tsx:489`), the combined currents + chlorophyll view (`chl=1`), the first-visit intro card, and the skip link on `/` (Explore has no `#main` and no skip link).
