Neritic · brand concepts, v4 (bathymetric)

Three directions. Wordmark face: Literata (TypeTogether for Google Fonts, SIL OFL 1.1): a text serif drawn for screens with an optical-size axis, so it holds at 16–20 px nav sizes, and with a true italic, which carries the chart convention that water is lettered in sloped type. A and B use upright SemiBold; C uses SemiBold Italic, with Medium Italic spaced capitals for editorial labels. Wordmarks in the SVG files are outlined paths.
